# Controlled Glider Project
## Introduction
Hello hello! I am waiting on a delivery for another project so I figured it's a good time to start fleshing out the scope of my next adventure. I would like to create a powered glider that implements a simple pitch control system. This would involve designing a glider, control surfaces and electronics to accomplish this goal. I am doing this because control systems and RC planes always interested me. Creating my own glider with a controller to keep it wings level would be the ultimate application and practice of the skills I've learnt during university.
